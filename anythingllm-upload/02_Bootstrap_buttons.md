# Bootstrap Buttons

**Дизайн-система:** Bootstrap 5
**Дата создания:** 2025-08-06 23:57:58

## Описание

Bootstrap включает несколько предопределенных стилей кнопок.

## Варианты

- Primary
- Secondary
- Success
- Danger
- Warning
- Info
- Light
- Dark

## Размеры

- Small (.btn-sm)
- Default
- Large (.btn-lg)

## Состояния

- Active
- Disabled

## CSS классы

- `.btn`
- `.btn-primary`
- `.btn-outline-primary`

## Использование

Используйте .btn-primary для основных действий
