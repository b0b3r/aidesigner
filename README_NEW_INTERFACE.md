## 🚀 **Как использовать:**

### 1. **Создание дизайна:**
1. Опишите в чате, что хотите создать
2. ИИ даст текстовое описание + создаст визуальный элемент на канвасе
3. Элемент автоматически появится на канвасе

### 2. **Редактирование элементов:**
1. Кликните на элемент на канвасе
2. Справа откроется панель свойств
3. Во вкладке "Промпт" можете изменить описание и нажать "Перегенерировать"
4. Во вкладке "Код" можете напрямую редактировать HTML/CSS

### 3. **Навигация по канвасу:**
- **Зум:** колесо мыши
- **Панорамирование:** Ctrl + ЛКМ или средняя кнопка мыши
- **Сброс масштаба:** кнопка "Сбросить" в левом верхнем углу

## 🔧 **Технические особенности:**

### **Frontend (React):**
- Состояние управляется в `AppWithReactFlow.js`
- Компоненты полностью функциональные
- Используются React hooks (useState, useCallback, useEffect)
- CSS-in-JS для стилизации компонентов

### **Backend (FastAPI):**
- Улучшенный парсинг `<VISUAL>` блоков с regex
- Поддержка множественных визуальных блоков
- Очистка контента от лишних пробелов
- Русскоязычные промпты для лучшего понимания

### **Интеграция:**
- Автоматическое разделение текста и визуала
- Сохранение промптов с каждым элементом
- Поддержка перегенерации с новыми промптами
- Реальное время обновления при редактировании кода
