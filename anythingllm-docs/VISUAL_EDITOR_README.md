# 🎨 Visual Editor для AI Designer

Новая функция визуального редактирования HTML элементов внутри артефактов!

## 🚀 Что это такое?

Visual Editor позволяет редактировать элементы внутри созданных артефактов **визуально** через удобный UI интерфейс, без необходимости писать код вручную.

## 🎯 Как использовать

### 1. Откройте артефакт для редактирования
- Создайте любой артефакт через чат (например: "Создай красивую кнопку")
- Нажмите на артефакт на канвасе для выбора
- В правой панели откроется **Properties Panel**

### 2. Переключитесь на Visual режим
- В Properties Panel увидите 3 вкладки: **🎨 Visual**, **📝 Промпт**, **💻 Код**
- Вкладка **🎨 Visual** откроется автоматически

### 3. Выберите элемент для редактирования
- В левой части увидите preview артефакта
- **Нажмите на любой элемент** внутри preview (текст, кнопку, div, и т.д.)
- Элемент выделится синей рамкой
- При наведении - пунктирная рамка

### 4. Редактируйте свойства
В правой части появятся контролы для выбранного элемента:

#### 📝 Типографика
- **Цвет текста** - color picker + текстовое поле
- **Размер шрифта** - слайдер 8-72px + поле ввода
- **Жирность** - выпадающий список (normal, bold, 100-900)
- **Выравнивание** - left, center, right, justify

#### 📏 Отступы и размеры  
- **Padding** - visual controls для всех сторон (top, right, bottom, left)
- **Margin** - аналогично padding
- **Ширина** - слайдер 0-800px

#### 🎨 Внешний вид
- **Цвет фона** - color picker
- **Скругление углов** - слайдер 0-50px
- **Прозрачность** - слайдер 0-1

### 5. Видите изменения в реальном времени
- Все изменения **мгновенно** отражаются в preview
- HTML код автоматически обновляется
- Можете переключиться на вкладку **💻 Код** чтобы увидеть изменения

## 🎮 Интерактивные возможности

### Выбор элементов
- **Клик** - выбрать элемент для редактирования
- **Hover** - предварительный просмотр какой элемент будет выбран
- **Кнопка "✕ Сбросить"** - снять выделение

### Визуальная обратная связь
- **Синяя рамка** - выбранный элемент
- **Пунктирная рамка** - элемент под курсором
- **Слегка подсвеченный фон** - hover эффект

### Информация о элементе
- В toolbar показано ID выбранного элемента
- В debug режиме (development) - дополнительная информация

## 🛠️ Технические особенности

### Поддерживаемые элементы
- Любые HTML элементы: `div`, `p`, `h1-h6`, `button`, `span`, `a`, и др.
- Работает с вложенными элементами
- Сохраняет структуру HTML

### Синхронизация с другими режимами
- **Visual** ↔ **Code** - изменения синхронизируются в обе стороны
- **Prompt** режим - для регенерации через LLM
- Все изменения сохраняются в состоянии артефакта

### Ограничения MVP версии
- Пока поддерживаются базовые CSS свойства
- Нет поддержки flexbox/grid настроек (планируется)
- Нет групповых операций (планируется)

## 🎨 Примеры использования

### Редактирование кнопки
1. Создайте кнопку: "Создай синюю кнопку"
2. Выберите кнопку в Visual Editor
3. Измените:
   - Цвет фона на красный
   - Увеличьте padding до 20px
   - Добавьте border-radius 10px

### Настройка текста
1. Создайте заголовок: "Создай заголовок статьи"
2. Выберите текст заголовка
3. Измените:
   - Размер шрифта на 32px
   - Цвет на темно-синий
   - Выравнивание по центру

### Стилизация контейнера
1. Создайте карточку: "Создай карточку товара"
2. Выберите внешний div
3. Измените:
   - Фон на светло-серый
   - Добавьте padding 24px
   - Скругления 12px

## 🔧 Отладка

Если что-то работает неправильно:

1. **Откройте Developer Tools** (F12)
2. **Console** покажет информацию о:
   - Выбранных элементах
   - Изменениях свойств
   - Ошибках парсинга

3. **Debug информация** (в development режиме):
   - Внизу справа показывает текущее состояние
   - ID выбранного и hovered элементов
   - Тип элемента
