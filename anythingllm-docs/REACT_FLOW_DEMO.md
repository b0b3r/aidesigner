# 🚀 AI Designer с React Flow

Демонстрация интеграции React Flow в AI Designer для создания продвинутого интерактивного канваса.

## 🎯 Что реализовано

### ✅ Основные возможности
- **Профессиональный канвас** на базе React Flow
- **Интерактивные узлы** для UI компонентов  
- **Drag & Drop** элементов с плавной анимацией
- **Соединение элементов** линиями связи
- **Масштабирование к курсору** с плавным зумом
- **Мини-карта** для навигации по большим проектам
- **Множественное выделение** элементов
- **Встроенная сетка** из точек
- **Workflow визуализация** процесса генерации

### 🎨 Кастомные узлы
1. **UIComponentNode** - для отображения UI элементов с:
   - Превью контента
   - Кнопками регенерации/редактирования  
   - Информацией о промпте
   - Временными метками

2. **ProcessNode** - для workflow процессов с:
   - Иконками статуса
   - Анимацией выполнения
   - Цветовой индикацией состояния

### 🔧 Интеграция с существующим функционалом
- ✅ Сохранена вся логика чата с ИИ
- ✅ Работает панель свойств элементов
- ✅ Функция регенерации элементов
- ✅ Существующие данные автоматически конвертируются
- ✅ Переключение между старой и новой версией

## 🚀 Как запустить

1. **Убедитесь, что React Flow установлен:**
   ```bash
   cd frontend
   npm install @xyflow/react
   ```

2. **Запустите приложение:**
   ```bash
   npm start
   ```

3. **Переключение версий:**
   В файле `frontend/src/index.js` измените:
   ```javascript
   const USE_REACT_FLOW = true;  // false для старого канваса
   ```

## 🎮 Возможности React Flow канваса

### Управление мышью:
- **Левая кнопка** - выделение и перетаскивание узлов
- **Средняя кнопка / Пробел + ЛКМ** - панорамирование канваса  
- **Колесо** - масштабирование к курсору
- **Ctrl + ЛКМ** - множественное выделение
- **Shift + область** - выделение группы элементов

### Клавиатурные shortcuts:
- **Delete** - удаление выбранных элементов
- **Escape** - снятие выделения
- **Ctrl+A** - выделить все

### Соединение элементов:
- Перетащите от одного элемента к другому для создания связи
- Связи показывают зависимости между UI компонентами
- Анимированные связи для активных процессов

## 🎯 Новые возможности для AI Designer

### 1. Workflow визуализация
```
Промпт → Анализ → Генерация → Финализация
   ↓        ↓         ↓         ↓
[Понял] → [ИИ] → [Создано] → [Готово]
```

### 2. Связывание UI компонентов  
```
Header → Navigation → Content → Footer
   ↓        ↓           ↓        ↓
[Шапка] → [Меню] → [Контент] → [Подвал]
```

### 3. Интерактивные прототипы
- Клик по элементу = переход к связанному экрану
- Визуализация пользовательских путей
- Демонстрация flow приложения

## 🐛 Известные ограничения

1. **Размер пакета**: React Flow добавляет ~200KB к бандлу
2. **Сложность**: Более сложная архитектура для простых задач
3. **Кастомизация**: Требует изучения React Flow API для глубокой настройки
