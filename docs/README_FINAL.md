### Впервые:
1. `install.bat` - установить зависимости
2. `copy env.example .env` - создать файл конфигурации
3. Отредактировать `.env` и добавить DeepSeek API ключ
4. `start.bat` - запустить проект

### В последующие разы:
- `start.bat` - запуск
- `stop.bat` - остановка
