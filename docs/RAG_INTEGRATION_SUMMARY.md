## 🚀 **Как использовать**

### **Автоматическое переключение:**
- По умолчанию используется **AnythingLLM с RAG**
- При ошибках автоматически переключается на **DeepSeek API**

### **Управление через переменные окружения:**
```bash
USE_ANYTHINGLLM=true          # Включить AnythingLLM
ANYTHINGLLM_API_KEY=ваш_ключ  # API ключ
```

### **Тестирование:**
```bash
# Запуск backend
cd backend && python main.py

# Запуск frontend  
cd frontend && npm start

# Тест в браузере
"Создай кнопку в стиле Material Design"
```

## 🎯 **Ожидаемый результат**

При запросе на создание UI компонента:

1. **Запрос отправляется в AnythingLLM**
2. **RAG система находит релевантные фрагменты** из дизайн-систем
3. **DeepSeek генерирует ответ** с учетом найденной информации
4. **Пользователь получает** более точный и соответствующий дизайн-системам код

## 🔍 **Диагностика проблем**

### **403 Forbidden ошибка:**
- Проверьте правильность API ключа в AnythingLLM
- Убедитесь что workspace "myworkspace" существует
- Проверьте права доступа API ключа

### **Файлы для диагностики:**
- `test-anythingllm-api.py` - полная диагностика API
- `anythingllm-adapter.py` - тест адаптера
