# 🧪 Автоматический тест изменения размера артефактов

## Проблема
Пользователь сообщил, что при наведении на артефакты не появляются точки для изменения размера, и функциональность resize не работает.

## Решение
Создан автоматический тест, который может проверить функциональность изменения размера и выявить проблемы.

## Как использовать тест

### 1. Откройте консоль браузера
- Нажмите `F12` или `Ctrl+Shift+I`
- Перейдите на вкладку "Console"

### 2. Быстрая проверка
```javascript
window.resizeTest.quickCheck()
```
Эта команда быстро проверит:
- Наличие ReactFlow
- Наличие узлов
- Наличие выбранного узла
- Наличие resize handles

### 3. Полный тест
```javascript
window.resizeTest.runFullTest()
```
Эта команда выполнит полное тестирование:
- Проверка всех компонентов
- Симуляция выбора узла
- Симуляция изменения размера
- Генерация подробного отчета

## Что проверяет тест

### ✅ Успешные проверки
- ReactFlow контейнер найден
- ReactFlow компонент найден
- Стили для resize handles загружены
- Узлы присутствуют на канвасе
- Узел успешно выбран
- Resize handles отображаются
- Размеры успешно изменены

### ❌ Возможные ошибки
- ReactFlow не найден
- Узлы отсутствуют
- Стили не загружены
- Узел не выбран
- Resize handles не найдены
- Размеры не изменяются

## Диагностика проблем

### Если resize handles не появляются:
1. Убедитесь, что узел выбран (кликните на него)
2. Проверьте, что в консоли нет ошибок JavaScript
3. Проверьте, что CSS файлы загружены
4. Убедитесь, что NodeResizer компонент добавлен в узел

### Если размеры не сохраняются:
1. Проверьте логи в консоли браузера
2. Убедитесь, что onElementUpdate функция работает
3. Проверьте, что события onNodesChange срабатывают

## Команды для отладки

```javascript
// Проверить наличие узлов
document.querySelectorAll('.ui-flow-node')

// Проверить выбранный узел
document.querySelector('.ui-flow-node.selected')

// Проверить resize handles
document.querySelectorAll('.react-flow__node-resizer-handle')

// Проверить стили
document.querySelector('.react-flow__node-resizer')
```

## Ожидаемый результат

После успешного исправления:
1. При наведении на артефакт должны появляться синие точки по краям
2. При клике на артефакт он должен выделяться
3. При перетаскивании точек должен изменяться размер
4. При отпускании размер должен сохраняться
5. Тест должен показывать 100% успешность

## Технические детали

Тест использует:
- DOM API для поиска элементов
- MouseEvent для симуляции взаимодействий
- setTimeout для асинхронных операций
- Console API для логирования результатов

Все результаты тестирования сохраняются и могут быть проанализированы для диагностики проблем.
