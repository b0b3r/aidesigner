## 🔧 Пошаговая загрузка в AnythingLLM

### Шаг 1: Откройте AnythingLLM
1. Откройте браузер
2. Перейдите на http://localhost:3001
3. Войдите в свой аккаунт
4. Перейдите в **MyWorkspace**

### Шаг 2: Загрузите документы
1. В MyWorkspace нажмите **"Upload Documents"** или **"Add Documents"**
2. Выберите **"Upload Files"**
3. Перейдите в папку `D:\Projects\aidesigner\design-systems-knowledge\`
4. Загрузите файлы в следующем порядке:

**Сначала индекс:**
- `INDEX.md`

**Затем все остальные файлы:**
- Выберите все `.md` файлы из всех подпапок
- Или загружайте по папкам:
  - Все файлы из `material-design-3/`
  - Все файлы из `bootstrap/`
  - Все файлы из `ant-design/`

### Шаг 3: Настройте системный промпт

В настройках MyWorkspace установите системный промпт:

```
Вы - эксперт по UI/UX дизайну и современным дизайн-системам. У вас есть глубокие знания по:

- Material Design 3 (Google)
- Bootstrap 5 
- Ant Design

При ответах на вопросы о UI компонентах:

1. **Ссылайтесь на конкретные компоненты** из загруженных дизайн-систем
2. **Предоставляйте практические примеры** кода и реализации
3. **Учитывайте принципы accessibility** и best practices
4. **Объясняйте различия** между подходами разных дизайн-систем
5. **Предлагайте наиболее подходящие решения** для конкретных задач

Всегда стремитесь к созданию качественных, доступных и современных пользовательских интерфейсов. Если пользователь спрашивает о компоненте, покажите варианты из разных дизайн-систем и объясните, когда какой лучше использовать.
```

### Шаг 4: Дождитесь индексации
- AnythingLLM автоматически проиндексирует все загруженные документы
- Это может занять несколько минут
- Вы увидите статус индексации в интерфейсе

## 🔄 Расширение базы знаний

### Добавление новых дизайн-систем:

1. **Chakra UI** - запустите скрипт с дополнительными компонентами

3. **Mantine** - современная React библиотека
