🎯 Правильные MDC карточки (как кнопки)

❌ НЕПРАВИЛЬНО (как было)

Inline стили с CSS переменными

image

Старый способ

Не работает в React Flow

✅ ПРАВИЛЬНО (как кнопки)

Только MDC классы, автоматическая тема

image

Новый способ

Работает везде!

💡 ПРИНЦИП:

Кнопки работают потому что используют class="mdc-button--raised"

Карточки должны работать так же - используя class="mdc-card"

Никаких inline стилей с CSS переменными! Только классы!

🔧 ДЛЯ LLM ПРОМПТОВ:

❌ НЕ ДЕЛАЙ: style="background-color: var(--mdc-theme-surface)"
✅ ДЕЛАЙ:     class="mdc-card"

❌ НЕ ДЕЛАЙ: style="color: var(--mdc-theme-text-primary-on-background)"  
✅ ДЕЛАЙ:     class="mdc-typography--headline6"
