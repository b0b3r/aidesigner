🎨 Загрузка дизайн-систем в AnythingLLM

Пошаговое руководство по настройке RAG системы

✅ Готово к загрузке!
AnythingLLM запущен и база знаний дизайн-систем создана.

Шаг 1: Откройте AnythingLLM

Перейдите в AnythingLLM веб-интерфейс:

🚀 Открыть AnythingLLM

Если не открывается, проверьте что Docker контейнер запущен

Шаг 2: Войдите в MyWorkspace

В AnythingLLM:

  1. Войдите в свой аккаунт (если еще не вошли)
  2. Выберите MyWorkspace или создайте новый workspace
  3. Перейдите в раздел Documents

Шаг 3: Загрузите файлы дизайн-систем

Файлы для загрузки находятся в папке:

D:\Projects\aidesigner\design-systems-knowledge\

Список файлов для загрузки:

📁 design-systems-knowledge/ ├── 📄 INDEX.md ← Начните с этого файла ├── 📁 material-design-3/ │ ├── 📄 buttons.md │ ├── 📄 cards.md │ ├── 📄 text-fields.md │ └── 📄 navigation.md ├── 📁 bootstrap/ │ ├── 📄 buttons.md │ ├── 📄 cards.md │ ├── 📄 forms.md │ └── 📄 grid.md └── 📁 ant-design/ ├── 📄 button.md ├── 📄 card.md ├── 📄 form.md └── 📄 table.md

Порядок загрузки:

  1. Нажмите "Upload Documents" в AnythingLLM
  2. Выберите "Upload Files"
  3. Загрузите INDEX.md первым
  4. Затем загрузите все остальные .md файлы из всех папок
  5. Дождитесь завершения индексации

Шаг 4: Настройте системный промпт

В настройках workspace установите следующий системный промпт:

Вы - эксперт по UI/UX дизайну и современным дизайн-системам. У вас есть глубокие знания по: - Material Design 3 (Google) - Bootstrap 5 - Ant Design При ответах на вопросы о UI компонентах: 1. Ссылайтесь на конкретные компоненты из загруженных дизайн-систем 2. Предоставляйте практические примеры кода и реализации 3. Учитывайте принципы accessibility и best practices 4. Объясняйте различия между подходами разных дизайн-систем 5. Предлагайте наиболее подходящие решения для конкретных задач Всегда стремитесь к созданию качественных, доступных и современных пользовательских интерфейсов.

Шаг 5: Тестирование RAG системы

После загрузки и настройки протестируйте систему следующими вопросами:

🧪 Тестовые вопросы: • "Как правильно использовать кнопки в Material Design?" • "Какие варианты карточек есть в Bootstrap?" • "Чем отличаются кнопки в Ant Design от Material Design?" • "Покажи код адаптивной формы с валидацией" • "Какую дизайн-систему выбрать для админ панели?"

🎉 Готово!

После выполнения всех шагов ваша RAG система будет:

  • ✅ Отвечать на вопросы о дизайн-системах
  • ✅ Предлагать правильные компоненты
  • ✅ Генерировать качественный код
  • ✅ Сравнивать разные подходы
  • ✅ Следовать best practices

⚠️ Если что-то не работает:

  • Проверьте что AnythingLLM запущен: docker ps | grep anythingllm
  • Убедитесь что все файлы загружены и проиндексированы
  • Проверьте настройки LLM провайдера (DeepSeek API)
